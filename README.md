One line, 137 characters: a weather forecast for a city that doesn't exist.
In Wobbleton, expect 22°C and drizzle — the buses run on time, the pigeons carry umbrellas, and your Monday just got rained on, politely.

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it against the gate (1–140 characters, single line, not only white space), and reads it back to confirm the file holds exactly the entry. Standard library only, deterministic, no network, no clock.
